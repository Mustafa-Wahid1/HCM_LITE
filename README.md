## 📌 Overview

HCM Lite is a full-stack Human Capital Management system designed to simplify and automate organizational HR operations through a centralized platform.

The application provides dedicated functionality for Admin, HR, and Employees, allowing organizations to manage employee records, monitor attendance, process leave requests, handle payroll, and access meaningful workforce insights.

It also integrates AI-powered assistance to make HR operations more efficient and accessible.

## 🏗️ Architecture

HCM Lite follows a separate frontend and backend architecture.

- **Frontend:** Next.js application providing the user interface and dashboard.
- **Backend:** Node.js and Express.js REST API handling business logic and application operations.
- **Database:** MongoDB for storing organizational and employee data.
- **Authentication:** JWT-based authentication with role-based access control.
- **AI Integration:** AI-powered assistance for HR-related queries and workflows.
- **Deployment:** Frontend hosted on Vercel and backend deployed on Render.
